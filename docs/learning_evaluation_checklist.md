# 学习调度评测清单

## A. 协议与环境接口

- [x] `resource-contract-v1` 仍可校验，本轮未暗中修改冻结口径。
- [x] 独立学习环境不导入传感器、通信和融合实现。
- [x] 一步定义为固定 tick，动作槽位在 episode 内稳定。
- [x] 剩余时间和剩余资源进入观测。
- [x] 全部任务解决、资源耗尽和自然时域是 `terminated`。
- [x] 调用方更短运行上限是 `truncated`，且不做终端补计。
- [x] bootstrap 仅由 `terminated` 关闭；下一状态掩码与该语义一致。
- [x] 旧雷达环境默认有限任务语义，旧截断语义只能显式启用。

## B. 可手算案例和账本

- [x] 当步完成案例的奖励、返回和资源代价与解析值相等。
- [x] 等待后完成案例区分不折扣回报 1.75 与折扣回报 1.55。
- [x] 自然时域案例执行终端未解决补计。
- [x] 资源耗尽案例在未完成任务存在时自然终止。
- [x] `sum(step_cost)` 与从最终资源账本重算的消耗一致。
- [x] 外部截断案例不加终端罚、仍允许 bootstrap。

## C. 算法语义

- [x] 拉格朗日执行动作与两个 critic 的 target 动作相同。
- [x] 拉格朗日 target 动作使用同一份可行动作掩码。
- [x] 历史负结果保留，但不再宣称旧 critic 机制已被完整验证。
- [ ] 修复后小规模 smoke training 结束，且无 NaN/掩码越界/资源不守恒。
- [ ] 根据验证集而非测试集选择 checkpoint。

## D. 数据划分与封存

- [x] 训练、验证、测试场景名与种子两两不交叉。
- [x] 划分文件有 SHA-256 摘要，修改会使校验失败。
- [x] 普通代码路径读取测试集会失败。
- [ ] 最终测试前已冻结 commit、配置、算法、超参、checkpoint 和指标。
- [ ] 测试集只打开一次，结果未用于调参或换 checkpoint。

## E. 固定感知处理链

- [ ] 训练 manifest 记录传感器、测量、通信、关联、跟踪、融合与信息边界配置摘要。
- [ ] 所有调度器对比共用同一感知处理链摘要。
- [ ] 若感知链发生变更，已重做所有基线并以独立因子报告。
- [x] 跟踪/通信已知缺陷被列为环境限制，不计入调度算法功效。

## F. 大规模运行闸门

- [ ] A–E 中除“最终测试”外的必要项全部完成。
- [ ] 大规模多种子运行方案和计算预算单独审批。
- [ ] 未开始大规模训练时，报告不宣称有统计显著性。
